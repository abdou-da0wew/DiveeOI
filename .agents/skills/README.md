# DiveeOI built-in video skills

These workspace-facing copies mirror the built-in skill resources registered in packages/db/src/plugin/skill/bundled/coenx-video/index.ts. The application bundle includes the same skill prompts and their reference files; they do not depend on this directory being deployed.

The 19 skills cover the production entry point, the 17 visual-style prompts, explainer variants, B-roll, optional object separation, sound design, the Coenx authoring language, interactive Canvas, SVG-backed vector motion, timeline design, font/typography selection, accessibility, Targeted Learning, lightweight physics, storyboarding and validation.

The 16-family font library is stored in packages/coenx-video/assets/fonts/ and is embedded into interactive exports. This mirror includes the manifest, local WOFF2 files and the corresponding family license notices for workspace tools.

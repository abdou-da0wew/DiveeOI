# DiveeOI Code Quality Rules

Canonical code-shaping rules for this repository. `.zcoderules` / `.cursorrules` / `AGENTS.md`
point here. Per-package guides (`packages/*/AGENTS.md`) add local detail on top; these rules win
on conflict.

## Module shape

- Flat top-level exports + self-reexport at the bottom of each module file:

  ```ts
  // src/foo/foo.ts
  export interface Interface { ... }
  export class Service extends Context.Service<Service, Interface>()("@diveeoi/Foo") {}
  export const layer = Layer.effect(Service, ...)
  export const defaultLayer = layer.pipe(...)

  export * as Foo from "./foo"
  ```

- Consumers import the namespace projection: `import { Foo } from "@/foo/foo"`, then
  `yield* Foo.Service`, `Foo.layer`, `Foo.defaultLayer`.
- No `export namespace Foo { ... }` — not standard ESM, blocks tree-shaking, breaks the native
  TS runner.
- No barrel `index.ts` in multi-sibling directories (e.g. `src/session/`). Each sibling is its
  own file with its own self-reexport. In a single-file directory module `foo/index.ts`, use
  `export * as Foo from "."`.
- Namespace-private helpers stay as non-exported top-level declarations in the same file.

## Layer composition

- Do not silence dependency checks with `layer as never` / `LayerNode.make(layer as never, ...)`.
  If a real dependency is missing, wire it. A `defaultLayer` must be self-sufficient: every
  requirement it declares is provided within it, and every method it returns closes over its
  requirements at construction time — do not `yield* SomeService` inside a returned closure
  (that leaks a per-call requirement onto every caller).
- Remember Effect v4 semantics: `X.pipe(Layer.provide(A), Layer.provide(B))` builds `A` and `B`
  in isolation from each other — `B` never sees what `A` provided. Use `Layer.provideMerge` or a
  merged group when siblings must share services.
- `as never` casts at `LayerNode.make` call sites are a known workaround for Effect v4
  beta.74's opaque `RIn` propagation through `Layer.provide`/`Layer.provideMerge`. Acceptable at
  call sites; do not add new ones to hide real missing dependencies.
- Type errors between distinct `Context.Service<Self, Interface>()` classes: widen body types to
  `Body<A, E2, any>` rather than restructuring the service.

## Effect conventions

- `Effect.gen(function* () { ... })` for composition; `Effect.fn("Domain.method")` for named /
  traced effects; `Effect.fnUntraced` for internal helpers.
- `Effect.fn` / `Effect.fnUntraced` accept pipeable operators as extra args — avoid unnecessary
  outer `.pipe()` wrappers.
- `Effect.callback` for callback-based APIs; `Effect.void` instead of `Effect.succeed(undefined)`.
- Prefer `DateTime.nowAsDate` over `new Date(yield* Clock.currentTimeMillis)`.
- `DateTime.DateTime` has no `.year`/`.month`/`.day` — use `DateTime.toPartsUtc(now)` /
  `DateTime.toParts(now)`.
- `yield* new MyError(...)` over `Effect.fail(new MyError(...))` for early-failure branches.
- Guarded `.filter()` does not narrow union member types — use an explicit type-guard predicate.
- Runtime: `makeRuntime` (src/effect/run-service.ts) for services (shared `memoMap` dedupes
  layers); `InstanceState` (src/effect/instance-state.ts) for per-directory/per-project state.

## Schemas and errors

- `Schema.Class` for multi-field data; `Schema.brand` for single-value types;
  `Schema.TaggedErrorClass` for typed errors; `Schema.Defect` instead of `unknown`.
- In `packages/server/src/config`, follow the existing self-export pattern at the top of the
  file (e.g. `export * as ConfigAgent from "./agent"`).
- Brand types (`SessionID`, `ProviderID`, …) are not injectable tags — never `yield*` them;
  take them as parameters or read them from request/context input.

## Project constraints

- Effect version is `4.0.0-beta.74` — beta APIs (`Effect.fn`, `Effect.callback`,
  `effect/unstable/*`) are in use. Check the catalog version before upgrading.
- `@diveeoi/http-recorder` is test-only — never import it in production code.
- `packages/script` is an internal build tool, never an npm dependency of runtime code.
- Conditional imports in `packages/db` (`#sqlite`, `#pty`, `#fff`) need both Bun and Node
  implementations.
- Do not reference or revive TUI code — it was deleted.
- Verify at the layer you changed: run the server entry, not only the typecheck, when touching
  layer wiring. Heavy builds/typechecks run on the Colab session (`divee_typecheck_build`), not
  on the local machine.

## API endpoint reference

All endpoints are under `/targeted-learning` and require the same auth as the rest of the instance API.

### Setup

| Method | Path | Handler | Purpose |
|---|---|---|---|
| GET | `/setup` | `setupStatus` | Returns setup state from `setup.json` (8 steps, status, recommendedProfile) |
| POST | `/setup/start` | `setupStart` | Runs the full 8-step pipeline (probe → preflight → download → verify → runtime-check → golden-self-test → benchmark → recommend-profile) |
| POST | `/setup/repair` | `setupRepair` | Resets all step statuses for repair |
| POST | `/setup/cancel` | `setupCancel` | Cancels a running setup (stub) |
| POST | `/setup/import-local` | `setupImportLocal` | Imports model from a local folder (offline machines) |

### Settings

| Method | Path | Handler | Purpose |
|---|---|---|---|
| GET | `/settings` | `getSettings` | Returns settings with defaults applied + effective sources |
| PATCH | `/settings` | `updateSettings` | Updates settings (writes to global config layer) |
| GET | `/settings/schema` | `getSettingsSchema` | Returns JSON Schema with custom annotations (for UI form generator) |

## Database schema reference

### `books.db` (separate from main DiveeOI DB)

Located at `<dataDir>/targeted-learning/books.db`. SQLite WAL mode. 8 tables + 1 FTS5 virtual table + 3 triggers.

| Table | Purpose | Key columns |
|---|---|---|
| `meta` | Single-row metadata | `key`, `value` (schema_version, normalizer_version, embed_signature) |
| `books` | Book metadata | `id`, `slug`, `title`, `author`, `lang`, `source_hash`, `status`, `embed_signature`, `chunk_count` |
| `sections` | Parent chunks (LLM sees these) | `id`, `book_id`, `parent_id`, `level`, `title`, `page_start`, `page_end`, `ord`, `text`, `heading_path` |
| `chunks` | Child chunks (these get embedded) | `id`, `book_id`, `section_id`, `ord`, `page`, `text`, `text_norm`, `token_count` |
| `chunks_fts` | FTS5 over `text_norm` | Virtual table, `tokenize='unicode61 remove_diacritics 2'` |
| `chunk_vecs` | Embedding vectors | `chunk_id`, `vec` (base64 Float32Array, 1024 dims for bge-m3) |
| `ingest_jobs` | Ingest job queue | `id`, `book_id`, `stage`, `status`, `progress`, `checkpoint_json` |
| `book_notes` | Agent's findings per book | `id`, `book_id`, `kind`, `text`, `citations_json`, `embedding`, `stale` |

### FTS5 triggers

- `chunks_ai` — AFTER INSERT on `chunks` → insert into `chunks_fts`
- `chunks_ad` — AFTER DELETE on `chunks` → delete from `chunks_fts`
- `chunks_au` — AFTER UPDATE on `chunks` → delete + re-insert into `chunks_fts`

### Main DB additions

- Session metadata field carries `{ targetedLearning: { mode: "targeted", bookIds: [...], allowCalculator: bool } }` when a session is in targeted mode.

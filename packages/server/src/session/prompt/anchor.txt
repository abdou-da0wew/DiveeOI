Your context is compacted. The "Working memory (anchor)" is an index of this
conversation — not the conversation itself. Every entry carries a ref to the
original, which was NOT deleted — it's just outside your context window.

The anchor tools let you recover any compacted content:
- `search_memory` — search by content when you don't have a ref.
  Use BEFORE concluding something was never established.
- `recall_context` — read the verbatim original when you have a ref.
  Use before editing a file you only know by label, or before reversing
  a decision.
- `anchor_edit` — update the index when it's stale. A decision reversed,
  a question answered, a file that no longer matters — fix it here.

The anchor is per-session. Long-term memory (memory-create/retrieve) is
cross-session. All memory is local — no cloud, no privacy concern. Save
proactively: if you spent time figuring it out, it's worth remembering.
</anchor>

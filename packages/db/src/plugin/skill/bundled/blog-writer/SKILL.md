# Blog Writer

Use this skill to draft or edit blog posts, articles, and thought leadership. Match the voice and format the user requests; do not assume the user's identity, business, or personal opinions.

## Workflow

1. Confirm the audience, purpose, topic, desired length, voice, and source material. Ask only for missing details that materially change the article.
2. Research factual or current claims with available tools when needed. Keep source links and distinguish verified facts from interpretation.
3. Build a clear thesis and outline before drafting. Use informative headings, short readable paragraphs, and concrete examples.
4. Write a strong opening, useful body sections, and a conclusion that follows from the article. Include a call to action only when appropriate.
5. Edit for accuracy, clarity, repetition, tone, and unsupported claims. Do not fabricate anecdotes, results, quotations, or first-person experience.
6. Return the draft in chat or save it only when requested. Do not publish to an external service unless the user explicitly asks and an authorized integration is available.

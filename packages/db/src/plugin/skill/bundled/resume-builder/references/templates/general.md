# General Resume Template (industry-agnostic)

Applies when:
- The user doesn't yet have a clear target direction
- Cross-industry job hunting (one resume applied to different directions)
- Early-career / new-graduate candidates
- Industries outside the other three (education / healthcare / government / manufacturing / media, etc.)

## Structure

```
Name | Phone | Email | City | Target role / desired direction

[Personal Profile / Career Summary] (2-3 lines)
Key positioning + core capabilities + the single most persuasive achievement

[Work Experience / Internships] (reverse-chronological for experienced hires; new grads put internships below education)
Company | Role | Start-End dates
- Main responsibilities (one line)
- Key result 1 (quantified)
- Key result 2 (quantified)
- Cross-cutting / soft-skill evidence (one line)

[Education]
School | Major | Degree | Dates
- GPA / ranking / scholarships (only if above average)
- Relevant coursework / papers / projects (only role-relevant items)

[Skills & Certifications]
- Tools: advanced Excel / Word / PPT; Notion / Trello; other industry tools
- Languages: English level; other languages
- Certifications: only widely recognized ones

[Other Highlights] (optional, only for strong cases)
- Entrepreneurship / side projects
- Public speaking / content creation (with meaningful follower / readership numbers)
- Volunteering (sustained ≥ 1 year)
- Sports / arts achievements (provincial level or above / commercial recognition)
```

## Style

- Neutral and restrained; avoid overly industry-specific jargon
- Emphasize "transferable skills" in every experience: communication / drive / data / learning speed / customer focus / leadership
- Cross-industry candidates must state in the Summary "why this direction fits me"

## Length

- New grad / intern: 1 page
- 1-5 years: 1 page (at most 1.2 pages)
- 5+ years: 1-2 pages

The biggest risk of the general template is **looking like "jack of all trades, master of none"**. If that's how it reads, proactively suggest that the user:
- Pick their strongest direction and switch to the matching industry template
- Or prepare 2 versions (an internet version + a general version) to use in different contexts

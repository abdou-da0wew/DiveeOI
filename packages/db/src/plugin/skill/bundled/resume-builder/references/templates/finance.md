# Finance / Consulting / Business Resume Template

## Structure (investment-banking / consulting style, emphasizing the deal / case list)

```
Name | Phone | Email | LinkedIn | City

[Education] (finance / consulting roles put it first — school + GPA is a hard screen)
School | Major | Degree | Start-End dates
- GPA: X.XX/4.00 (Major: X.XX/4.00)
- Ranking / scholarships / honors
- Relevant core courses: Corporate Finance, Financial Modeling, ...
- Exchange / overseas experience

[Work Experience] (reverse-chronological)
Company | Department / Group | Role | Start-End dates, location
- Deal / Case 1: project name + your role + key contribution + deal size / outcome
- Deal / Case 2: same
- Deal / Case 3: same
(IB/PE typically lists 3-5 deals; consulting 3-5 cases; analysts can list coverage sectors + main views)

[Internships] (essential for new grads / early career, reverse-chronological)
(same structure as above)

[Skills & Certifications]
- Financial modeling: proficient in DCF / LBO / Comps / M&A models
- Advanced Excel / PowerPoint
- Bloomberg / Capital IQ / Wind / Choice
- CFA Level X / CPA / FRM / ACCA
- Programming (a plus for quant): Python / SQL / VBA
- Languages: English (IELTS 7.5 / GMAT 750), others

[Leadership / Extracurriculars] (only meaningful items)
- Student government / clubs: leadership role + quantified results
- Nonprofit projects: scale organized + impact
- International competitions: e.g. CFA Research Challenge regional top X
```

## Style Points

- **Every deal / case must include**: project type, client industry, your concrete actions (modeling / roadshows / research), and the outcome (financing amount / valuation / report page count / client decision)
- Investment banking emphasizes deal flow count + size; consulting emphasizes case variety + client seniority
- Quantification templates:
  - IB: "Participated in a $X00M ___ industry IPO/M&A, built the LBO / DCF model, produced a ___-page investor deck"
  - Consulting: "Ran a ___ project for a top-3 client in the X industry, quantitatively analyzed X market segments; the final recommendation was adopted and executed by the client ___"
- **School-tier sensitivity**: IB / consulting / PE generally only screen Tier 1 schools (C9 league, HKU, NUS, Ivy League / top-30 US schools, etc.). If the school isn't Tier 1, lean harder on internships / competitions / self-study

## Chinese and English Versions

Many finance / consulting employers **only accept English resumes** (foreign banks, MBB, IBD). This skill produces the Chinese version by default, but proactively ask: "Do you need an English version? I can generate both."

For the English version, note:
- Use American English (finance is predominantly US-style)
- Use past-tense action verbs: Led, Built, Drove, Analyzed, Advised
- Never use "we / our team" — use "I / my team"; emphasize individual contribution
- One page max (unless a senior candidate)

## Landmines

- An IB / consulting resume **without a deal / case list** → fatal; rewrite
- Writing "interned at ___" as a work entry → must convert into deal / case format
- Missing GPA / school / test scores → include even if low (unless it truly drags you down badly)
- Writing "interested in finance" / "hoping to enter investment banking" → delete; a resume is not a personal statement

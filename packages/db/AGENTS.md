# DB Package (@diveeoi/db)

Lower-level database, AI provider adapters, and session engine.

- **Conditional imports** via subpath imports in `package.json`:
  - `#sqlite` → `sqlite.bun.ts` / `sqlite.node.ts`
  - `#pty` → `pty.bun.ts` / `pty.node.ts`
  - `#fff` → `fff.bun.ts` / `fff.node.ts`
  - These resolve based on the runtime (`bun` vs `node`). When adding platform-specific code, add both implementations.
- **AI SDK providers bundled here** (not in a separate package) — 20+ `@ai-sdk/*` packages for OpenAI, Anthropic, Google, Bedrock, etc. This is the integration surface for AI providers.
- **Drizzle schema** is in `src/database/schema.gen.ts` (generated by Drizzle Kit). Migrations are in `src/database/migration/` — 35+ files with descriptive names (e.g. `familiar_lady_ursula`).
- **Session runner** (`src/session/runner/`) is the core execution engine. It handles LLM calls, model selection, message conversion, and event publishing.
- **Tool definitions** in `src/tool/` — 18 files covering bash, edit, glob, grep, read, write, websearch, webfetch, skill, todo, and more. These are the canonical tool implementations used by the runtime.
- **Public API surface** in `src/public/`: `Agent`, `Model`, `OpenCode`, `Session`, `Tool`, `Location`, `Prompt`, `AbsolutePath` — this is the intentional supported API.
- **Effect utilities** in `src/effect/`: `layer-node.ts` (the `LayerNode.make` function with `CheckDependencies` conditional type that needs `as never` casts), `keyed-mutex.ts`, `memo-map.ts`.
- **Config schemas** in `src/config/` — agent, provider, command, compaction, watcher, LSP, MCP, plugin, and more.
- **Observability** in `src/observability/` — logging, OTLP exporter, shared types.
- **Schema location**: `src/database/schema.gen.ts` is auto-generated. `src/schema.ts` has shared value-level schemas (like `AbsolutePath`).
- **`src/effect/layer-node.ts:25`** — `CheckDependencies` conditional type causes `as never` cast requirements at call sites when layers have opaque RIn.
